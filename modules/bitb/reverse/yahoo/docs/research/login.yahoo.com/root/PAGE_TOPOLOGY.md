# Page Topology

1. **Header (Overlay / Sticky)**
   - Contains Logo on the left and Help/Terms/Privacy links on the right.
   - Visually sits on top of the background.

2. **Main Background**
   - On desktop, contains a promotional graphic (e.g., 1000GB Yahoo Mail) spanning the left and background.
   - Implemented via an iframe or background images. 

3. **Login Card**
   - Floats over the background, right-aligned on desktop, centered on mobile.
   - Contains the sign-in form, links, and buttons.
